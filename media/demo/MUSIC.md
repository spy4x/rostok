# Music for the rostok demo video

`music.opus` is the music the rostok demo video's encoder lays under the video.

- Title: Swimming with the fish
- Author: Komiku
- Album: Poupi's incredible adventures! (2018)
- Source:
  https://freemusicarchive.org/music/Komiku/Poupis_incredible_adventures_/Komiku_-_Poupis_incredible_adventures__-_39_Swimming_with_the_fish
- Copy downloaded from Wikimedia Commons:
  https://commons.wikimedia.org/wiki/File:Komiku_-_39_-_Swimming_with_the_fish.ogg
  (file: https://upload.wikimedia.org/wikipedia/commons/3/38/Komiku_-_39_-_Swimming_with_the_fish.ogg)
- Licence: CC0 1.0 Universal, a public domain dedication
  (https://creativecommons.org/publicdomain/zero/1.0/). Both pages above state it. It allows
  commercial use with no attribution; this file names the source anyway.

The file here (`music.opus`) is 90 seconds of the track starting at 0:12, where it is already steady, re-encoded
to Opus at 96 kbit/s, stereo, with all metadata removed and no other change. The video's encoder trims
it to the video's length, sets its level, and fades it in and out.
