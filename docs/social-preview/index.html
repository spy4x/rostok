rostok 🌱

Scaffold a self-hosted homelab from a curated catalog.

Pick Docker Compose stacks, keep secrets encrypted in Git, deploy over SSH.

deno install -g -A -n rostok jsr:@rostok/cli

$ rostok
? Server name (home) › home
? SSH target › jane@home.example.com
? Domain › example.com
? Pick stacks › traefik, gatus, immich
added immich to home: 9 new values, 0 kept

$ rostok deploy home
Syncing files to jane@home.example.com:/srv/apps...
✅ Successful (3/3): ✓ traefik ✓ gatus ✓ immich
