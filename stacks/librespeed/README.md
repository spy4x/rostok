# LibreSpeed

Self-hosted internet speed test — no Flash, no Java, no client-side install.

## Features

- Browser-based speed test (download/upload/latency)
- No persistent data storage
- Password-protected results
- Lightweight, stateless

## Access

Web UI: `https://speed.${DOMAIN}`

## Configuration

```bash
MODE=standalone
PASSWORD=${LIBRESPEED_PASSWORD}
```

Password protects the settings panel. Test runs are public.
