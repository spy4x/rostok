# Paperless-ngx

Document management system — scan, index, and search your documents.

## Features

- OCR with machine learning classification
- Automatic document tagging and correspondence matching
- Full-text search
- Document consumption via hot folder, API, or mobile app
- Email ingestion
- GPU-accelerated OCR (NVIDIA CUDA)
- Multi-user with granular permissions

## Access

Web UI: `https://docs.${DOMAIN}`

- [iOS App](https://apps.apple.com/app/paperless-mobile/id1546311932)
